DevMetrics – Personal Coding Analytics Platform
DevMetrics is a full-stack web application that enables developers to track, analyze, and visualize their coding activity across multiple platforms such as Codeforces and GitHub.

The platform securely authenticates users, fetches real-time data from public APIs, and presents meaningful insights through interactive dashboards and analytics.

Project Features:
User authentication with profile-specific dashboards
Platform linking for Codeforces and GitHub
Real-time data fetching using external REST APIs
Interactive analytics including monthly problems solved, rating trends, and commit activity
Clean and responsive dashboard user interface
Scalable backend architecture to support future platform integrations
